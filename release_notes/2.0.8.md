# Cartouche Stream 2.0.8 - 2026-11-03

## Changes

- Clicking the pairing notification opens Cartouche's own pairing screen when Cartouche is installed, instead of the settings page, which asks for a login Cartouche players never set. Without Cartouche, it still opens the settings page.
- The tray, its notifications and the program's description in Windows say Cartouche Stream.

## Good to know

- The installer is still unsigned: Windows shows "unknown publisher", and new installs skip the virtual gamepad driver (gamepads go through ViGEmBus when it is installed).
