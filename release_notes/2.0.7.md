# Cartouche Stream 2.0.7 - 2026-11-03

Cartouche Stream is the streaming server of [Cartouche](https://cartouche.borderline.games): play your Cartouche games on your phone, tablet or TV with Moonlight. It is a fork of [Vibeshine](https://github.com/Nonary/vibeshine) 2.0.6 (itself a fork of Sunshine), under the same GPL-3 license. Cartouche installs and sets it up for you; you do not need to run this installer by hand.

## Changes from Vibeshine 2.0.6

- Its name in Windows: the service, the Start menu, the tray menu and the installer window say Cartouche Stream, with Cartouche's icon.
- The advanced settings page only opens from this PC by default (`origin_web_ui_allowed = pc`). Moonlight pairing and streaming on your network are unchanged.
- Update checks follow this repository's releases.

## Good to know

- The installer is not signed yet: Windows shows "unknown publisher".
- It installs to the same folder and service as Vibeshine (`C:\Program Files\Sunshine`, `SunshineService`) and replaces a Vibeshine already installed.
- The virtual gamepad driver only installs from signed builds, so this build skips it; the virtual display driver installs as in Vibeshine.
